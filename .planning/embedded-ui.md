# 电子纸应用与开发板无屏仿真

## 验收目标

ESP32-P4 连接电脑、P6 屏幕断开时，运行共享 LVGL 9 布局及语义按键路由；通过 USB 收到板端完整 400×300 单色帧，在电脑生成 PNG 并目视校准。主机渲染用于固定输入回归。真实面板波形和 BUSY 电平保持随货资料核实边界。

## 提交划分

1. 共享 LVGL I1 布局、路由生命周期、帧转换与主机图片回归。
2. 板端单任务 UI、有效 Kconfig、USB 帧导出和主机接收工具。
3. 开发板无屏验证、图片校准记录、使用说明与最终检查。

## 验证依据

- Clang C++26、clang-format、clang-tidy、CTest。
- 固定状态下所有页面的 PNG、布局边界、像素差异、异常包检测。
- ESP-IDF 完整编译及实际 USB 回传的帧；串口按键模拟和物理按键共用路由入口。
- 帧回传包含序号、长度、校验和；所有行完整后才生成图片。
- 回传与布局操作串行执行；大帧保存在静态/对象存储区。
