## 控制器级事实

SSD1683 Rev 1.0 第 5、8、10–12、43–45 页：

- 两块 400x300 bit RAM；单块 15,000 字节。
- VCI 工作范围 2.3–3.7 V，VDDIO 接 VCI。项目面板范围采用上表 2.3–3.6 V。
- BS1 低选择四线 SPI，高选择九位三线 SPI；按实物硬件配置选择。
- 四线 SPI 的信号为 SCL、SDA、CS#、D/C#；CS# 低有效，D/C# 低表示命令、高表示数据，D7 先发送，数据在时钟上升沿采样。
- RES# 低有效；芯片 BUSY 高为忙，此时不可发送命令。转接电路可能改变主控侧有效电平。
- 写时钟最高 20 MHz，读时钟最高 2.5 MHz，电气条件见第 45 页。初次点亮可采用 1 MHz 作为工程起点，实际速度还受面板和转接板限制。
- 内部温度传感器在 -25–50 ℃标称精度 ±2 ℃；面板可用温度仍采用上表。

## 帧缓冲与坐标

项目黑白画布每行 50 字节，整帧 15,000 字节；保存新旧两帧需要 30,000 字节。控制器 RAM 的反相选项会影响显示语义，渲染层可约定 1 为白、0 为黑，再由驱动集中处理映射。

常见位打包为 `offset = y * 50 + x / 8`、`mask = 0x80 >> (x % 8)`。实际扫描方向、data-entry mode 和旋转需用四角图案验证。局刷 X 区域按 8 像素边界扩展并裁剪到屏幕边界，扩展区域保留相应旧画面。

## 接线前需核实

原厂 PDF 当前未成功取得。以下信息需从随货资料、实物标签或版本匹配的原厂 PDF 确认：裸屏/驱动模块形态、FPC 针数和触点方向、连接器针序、升压外围、逻辑电平转换、BUSY 反相、复位时序、供电入口和峰值电流。

ESP32-P4 侧按实际接口配置 SCLK、数据输出、CS、D/C、RESET、BUSY 和可选电源使能；GPIO 编号在接线确认后分配，并核对项目既有 UART 和其他外设占用。读取寄存器时还需确认 SDA 双向连接能力。

FPC 固定后再调试，限制反复弯折和机械应力。5 V 输入必须具有对应转接板的明确支持证据。
