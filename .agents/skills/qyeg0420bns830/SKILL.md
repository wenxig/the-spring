# QYEG0420BNS830

项目使用奇耘 QYEG0420BNS830，由 ESP32-P4 的 C++ 固件通过 SPI 管理。

## 资料入口

- 接线、供电、尺寸和像素格式：读取 [硬件参考](references/hardware.md)。
- 初始化、刷新、休眠、故障诊断：读取 [驱动流程](references/driver-flow.md)。
- 原厂附件、控制器手册、证据页码及访问限制：读取 [资料来源](references/sources.md)。

## 实施规则

1. 先核对屏幕标签、FPC 后缀、转接板版本及其电路。采用奇耘本型号资料确认针序、复位时序、LUT、VCOM 和初始化参数；缺少证据的字段保持待确认，不生成猜测接线表。
2. 规格采用本屏商品页及版本匹配的原厂资料；控制器语义采用 SSD1683 手册；同类模块代码用于交叉检查。屏幕与转接板各自的电压、针序和波形要求分别核实。
3. 产品绘制采用 400x300 黑白双态图像，单帧 15,000 字节。颜色能力由面板确定。控制器其他 RAM 通道的用途按实际波形模式核对。
4. ESP32-P4 使用项目 C++ 工具链，组合封装 SPI、GPIO、单调时钟和刷新策略，外设资源采用 RAII 管理。板级 GPIO、BUSY 有效电平和 SPI 频率通过配置注入。
5. 以 3.3 V 作为项目逻辑域。裸屏需要匹配的驱动外围电路；连接器、供电入口和外围要求确认后再落具体接线。
6. BUSY 等待设截止时间和有限恢复次数；刷新成功后提交旧帧状态，失败时标记面板状态未知，恢复后重新建立全帧基准。
7. 先完成全白、全黑、棋盘格及四角图案验证，再启用局刷。局刷次数、间隔与全刷阈值依据本屏温度和残影实测配置。
8. 刷新完成后按已验证序列关闭高压并休眠；唤醒执行硬件复位与初始化。断电或 RAM 状态未知时重新写入全帧。

交付时注明面板版本、波形来源和验证条件。将原厂规格、控制器能力、工程建议和实测结果明确标注。
