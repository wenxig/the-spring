# 移远 EC600X-EVB 硬件架构与引脚映射

本文档记录移远 EC600X-EVB 的硬件规格、电源架构与排针资源。开发板支持 **EC600N-CN、EC600U-CN、EC600M-CN**；本项目当前实装 **EC600MCNLE**。

参考文档：<https://developer.quectel.com/doc/quecpython/Dev_board_guide/zh/ec600x-evb.html>
官方原理图：<https://developer.quectel.com/wp-content/uploads/2024/09/EC600X_EVB_V3.2-SCH.pdf>

---

## 1. 核心硬件规格

| 参数项 | 详细规格 |
| :--- | :--- |
| **适配模组** | **EC600N-CN、EC600U-CN、EC600M-CN**（LTE Cat 1 bis，支持 10Mbps 下行 / 5Mbps 上行） |
| **项目实装** | 移远 **EC600MCNLE** |
| **供电方式** | Type-C 接口 5V 供电 / 外部 DC 电源输入（板载滑动电源开关切换） |
| **板载电源轨** | 5V 输入、约 3.8V `VBAT`、3.3V、1.8V `VDD_EXT` |
| **板载传感器** | **AHT20** 温湿度传感器 (I2C 接口)、**GT36528** 光敏电阻 (ADC 通道) |
| **音频外设** | **GMI6050P-66DB** 模拟麦克风、**NS4160** 音频功放驱动板载喇叭接口 |
| **扩展排针** | 2 组 18-Pin 2.54mm 排针 (J5 与 J6)，引出所有串口、SPI、I2C、ADC、PWM 与电源线 |
| **其他外设** | Micro SIM 卡座、SMA/IPEX LTE 天线接口、NET 网络指示灯、PWRKEY 开机按键、RESET 复位按键 |

## 4. 板载资源与控制信号

| 板载资源 | 模组引脚 / 接口 | 说明 |
| :--- | :--- | :--- |
| **AHT20** | Pin56 / Pin57 | I2C1，分别为 SDA / SCL |
| **GT36528** | Pin19 | J6 Pin4，ADC0 |
| **GMI6050P-66DB** | Pin23 / Pin24 | 麦克风 SPK 输入 |
| **NS4160** | Pin21 / Pin22 | 功放 SPK 输出，连接板载扬声器 |
| **可选 LCD ST7789** | Pin63～Pin67 | SPI 接口，具体功能按官方原理图确认 |

官方 V3.2 原理图显示，J5 的 UART、SPI、I2C 等总线经过 `TXS0108E` 类电平转换后连接到 3.3V 侧。**PWRKEY、RESET_N、MAIN_RI** 位于模组侧控制网络，未引出到 J5/J6；外部主控接入这些信号时，必须另行设计与模组电平、开漏/下拉方式匹配的电路，并按所装模组硬件手册执行时序。

## 5. 上电启动与硬件避坑指南

1. **电源选择开关**:
   - 板载滑动开关用于切换供电来源：使用 USB 线调试时务必拨至 **USB** 挡；使用外部适配器供电时拨至 **DC** 挡。
2. **开机时序**:
   - 上电后供电稳定至少 30ms。
   - 长按板载 **PWRKEY** 按键（约 1 秒）开机，板载 NET 指示灯开始闪烁，表明模组已进入网络搜网与注册流程。
3. **电平兼容性**:
   - J5 的总线信号位于 EVB 3.3V 侧；J6 Pin 3 为模组 `VDD_EXT` 的 1.8V，J6 Pin 18 为约 3.8V 的 `VBAT`。使用排针时分别核对信号和供电电压，禁止将 J6 Pin 3 当作 3.3V 电源或将 J6 Pin 18 接入 3.3V 逻辑。
