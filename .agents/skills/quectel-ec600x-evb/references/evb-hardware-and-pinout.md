# 移远 EC600X-EVB 硬件架构与引脚映射

本文档详细记录移远 QuecPython EC600X-EVB（针对搭载 EC600M 模组）的硬件规格、电源架构与排针资源。
参考文档：<https://developer.quectel.com/doc/quecpython/Dev_board_guide/zh/ec600x-evb.html>

---

## 1. 核心硬件规格

| 参数项 | 详细规格 |
| :--- | :--- |
| **搭载模组** | 移远 **EC600M-CN**（LTE Cat 1 bis，支持 10Mbps 下行 / 5Mbps 上行） |
| **供电方式** | Type-C 接口 5V 供电 / 外部 DC 电源输入（板载滑动电源开关切换） |
| **板载电源轨** | 5V、3.3V (通过板载 LDO/DCDC 降压)、1.8V (`VDD_EXT` 输出)、VBAT (3.8V 典型值) |
| **板载传感器** | **AHT20** 温湿度传感器 (I2C 接口)、**GT36528** 光敏电阻 (ADC 通道) |
| **音频外设** | **GMI6050P-66DB** 模拟麦克风、**NS4160** 音频功放驱动板载喇叭接口 |
| **扩展排针** | 2 组 18-Pin 2.54mm 排针 (J5 与 J6)，引出所有串口、SPI、I2C、ADC、PWM 与电源线 |
| **其他外设** | Micro SIM 卡座、SMA/IPEX LTE 天线接口、NET 网络指示灯、STATUS 状态灯、PWRKEY 开机按键、RESET 复位按键 |

## 4. 上电启动与硬件避坑指南

1. **电源选择开关**:
   - 板载滑动开关用于切换供电来源：使用 USB 线调试时务必拨至 **USB** 挡；使用外部适配器供电时拨至 **DC** 挡。
2. **开机时序**:
   - 上电后供电稳定至少 30ms。
   - 长按板载 **PWRKEY** 按键（约 1 秒）开机，板载 NET 指示灯开始闪烁，表明模组已进入网络搜网与注册流程。
3. **电平兼容性**:
   - EVB 板载排针引出的部分信号已经过板载电平转换至 3.3V，若直接使用引脚时务必核实 J6 Pin 3 (1V8) 与 J6 Pin 2 (3V3) 的电平关系，避免 3.3V 直灌模组裸引脚。
