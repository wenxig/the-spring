# EC600M 硬件设计与低功耗参考手册

本文档详细总结 Quectel EC600M 系列（含 EC600M-CN 等）LTE Cat 1 bis 模组的硬件电路设计、供电方案、开机/复位时序、引脚电气特性、低功耗休眠（Sleep Mode/Enhanced Sleep Mode）及射频 PCB 设计规范。

---

## 1. 供电系统设计 (VBAT & VDD_EXT)

### 1.1 VBAT 电气要求与波动抑制
EC600M 模块通过 VBAT 引脚供电（包括 VBAT_BB 基带供电和 VBAT_RF 射频供电）：
- **输入电压范围**：`3.4 V ~ 4.5 V`
- **推荐工作电压**：`3.8 V`
- **瞬态跌落要求**：在 LTE/GSM 发射脉冲期间，瞬态电流可能高达 **2.0 A**。在此大电流冲击下，VBAT 引脚上的瞬态跌落不得低于 **3.3 V**，跌落恢复时间需尽可能短，否则将导致模块欠压异常关机或重启。

### 1.2 推荐供电电路拓扑
1. **LDO / DC-DC 选型**：
   - 供电芯片输出电流能力必须保证持续 **$\ge 2.0\ \text{A}$**，推荐选用低纹波、高动态响应的降压型 DC-DC 或大电流专用 LDO（如 MIC29302、TI TPS5430、LM2596 等）。
2. **去耦滤波电容网络（布局必须紧贴模块 VBAT 引脚）**：
   - **储能大电容**：并联 1 颗 $100\ \mu\text{F} \sim 470\ \mu\text{F}$ 低 ESR 钽电容或高分子铝电解电容，用于平抑瞬态突发电流跌落。
   - **RF 滤波电容**：并联 $33\ \text{pF}$（滤除中高频 RF 干扰）和 $10\ \text{pF}$（滤除高频 RF 干扰）陶瓷电容。
   - **基带滤波电容**：并联 $0.1\ \mu\text{F}$ 和 $1\ \mu\text{F}$ 陶瓷电容。
   - **TVS 二极管**：并联 1 颗瞬态抑制二极管（反向截止电压 $5.0\ \text{V}$，峰值脉冲功率 $\ge 500\ \text{W}$），防止过压和浪涌击穿。
3. **PCB 走线规范**：
   - VBAT 走线宽度不得低于 **2.0 mm**，若条件允许建议铺铜走线，并在走线周围布置密集的屏蔽地孔（GND Via）。
   - 避免 VBAT 走线穿过射频、时钟线、高频敏感区域。

### 1.3 VDD_EXT 供电输出
- `VDD_EXT` 为模块内部输出的基带参考电平，供电电压为 **1.8 V**，最大输出驱动能力约 **50 mA**。
- 可用作外部电平转换芯片的基准参考源，或作为模块开机成功的硬件状态指示（开机成功后持续输出 1.8 V，关机后变为 0 V）。
- **切勿**将 VDD_EXT 作为大功率外设供电电源使用。

## 2. 核心控制引脚与时序管理

### 2.1 开机流程与 PWRKEY 时序
`PWRKEY` 引脚内部已弱上拉至 1.8V（或 VBAT），开机通过将 PWRKEY 拉低至 GND 实现：
1. **VBAT 建立延时**：VBAT 电压稳定至 3.4V 以上后，需等待至少 **30 ms**，方可拉低 PWRKEY。
2. **拉低持续时间**：拉低 PWRKEY 持续时间必须在 **700 ms ~ 1000 ms** 之间。
3. **释放与检测**：释放 PWRKEY（变为高阻态），等待模块内部启动。当检测到 `VDD_EXT` 输出稳定 1.8V 且主串口输出 `RDY`，标志开机启动完成。

```
VBAT:      ───────┌──────────────────────────────────────────────
                  │ >30ms
PWRKEY:    ───────┐                ┌─────────────────────────────
                  │  700ms ~ 1000ms│
                  └────────────────┘
VDD_EXT:   ────────────────────────┌───────────────────────────── (1.8V)
Main UART: ────────────────────────┼────── RDY ───── +CPIN: READY
```

### 2.2 关机流程与安全保护
模块支持两种关机方式：
1. **AT 指令安全关机（推荐）**：
   - 主控发送 `AT+QPOWD=1`。
   - 模块开始注网、保存内部参数并安全卸载文件系统，待串口返回 `POWERED DOWN` 且 `VDD_EXT` 掉落至 0V 后，方可彻底切断 VBAT。
   - 此方式能够有效防止正在写入的 UFS/Flash 文件数据损坏。
2. **硬件 PWRKEY 关机**：
   - 将 `PWRKEY` 拉低持续 **$\ge 650\ \text{ms}$**，模块进入关机流程。
3. **硬件紧急断电（不推荐日常使用）**：
   - 直接切断 VBAT 供电。仅在系统崩溃无法响应时使用。

### 2.3 复位流程 (RESET_N)
`RESET_N` 用于硬件紧急复位：
- 内部已弱上拉至 1.8V。
- 当模块程序死锁或无响应超过 30 秒时，将 `RESET_N` 引脚拉低至少 **100 ms**，然后释放。
- 模块将执行硬件重启，开机时序重新开始。

## 3. 电平转换与串口接口设计

### 3.1 1.8V 电平隔离警告
**重要安全提示**：EC600M 系列所有数字 I/O（包括 MAIN_UART、DEBUG_UART、GPIO、RI、DTR 等）的工作电平均为 **1.8 V**。
- 若主控 MCU 为 **3.3 V** 供电，**严禁直连**！必须增加电平转换电路，否则会瞬间损坏模块内部基带芯片。

### 3.2 推荐电平转换方案

#### 方案 A：专用双向电平转换芯片（推荐）
- 选用支持 1.8V 和 3.3V 互转的双向转换芯片（如 TI 的 TXS0108E、TXB0104 等）。
- 芯片 A 侧接模块的 1.8V 域（参考电源接入模块 `VDD_EXT`）。
- 芯片 B 侧接 MCU 的 3.3V 域（参考电源接入主控 `VCC_3V3`）。

#### 方案 B：分立 N-MOS 管转换电路（低成本方案，适用于 TXD/RXD）
```
          +1.8V (VDD_EXT)             +3.3V (MCU_VCC)
                 |                           |
                [R1 10k]                    [R2 10k]
                 |                           |
  (EC600M_Pin) --+-------- S      D ---------+-- (MCU_Pin)
                           |      |
                           +-- G -+
                               |
                              +1.8V (VDD_EXT)
```
- MOS 管建议选用导通阻抗低、结电容小的高速 N 沟道 MOSFET（如 BSS138、2N7002）。

## 4. (U)SIM 卡电路设计规范

EC600M 内部支持 1.8V 和 3.0V 双电压 (U)SIM 卡自动识别。
- **SIM 引脚分配**：`USIM_VDD`, `USIM_DATA`, `USIM_CLK`, `USIM_RST`, `USIM_PRESENCE`。
- **保护电路**：
  - 在 SIM 卡座靠近引脚位置，每根信号线上必须加 **TVS 瞬态二极管**（结电容要求 $\le 15\ \text{pF}$），用于防止插拔卡时的静电浪涌击穿。
  - `USIM_DATA` 需在模块与卡座之间预留 1 颗 $10\ \text{k}\Omega$ 上拉电阻至 `USIM_VDD`（若模块内部已集成可不焊）。
  - `USIM_CLK`, `USIM_DATA`, `USIM_RST` 线上串联 $22\ \Omega$ 阻尼电阻，用于抑制过冲和反射。
  - `USIM_VDD` 靠近卡座引脚放置 $0.1\ \mu\text{F}$ 和 $1\ \mu\text{F}$ 滤波电容。
- **热插拔检测 (USIM_PRESENCE)**：
  - 支持高电平或低电平有效配置（通过 `AT+QSIMDET` 设置），可避免未断电拔卡损坏 SIM。

## 5. 射频天线与 PCB 走线设计规范

### 5.1 射频接口特性与阻抗控制
- **RF_ANT 引脚**：单端天线输入/输出引脚。
- **特性阻抗**：必须严格控制为 **$50\ \Omega \pm 10\%$**。
- **微带线 / 共面波导设计**：
  - 必须采用带完整地参考平面的射频微带线（Microstrip Line）或带有两侧伴随地线的接地共面波导（CPW）。
  - 射频走线两侧需打密集的接地过孔，过孔间距 $\le \lambda / 10$（实际布板间距约 $1.0\ \text{mm} \sim 1.5\ \text{mm}$）。

### 5.2 阻抗匹配网络与 ESD 防护
- 天线引脚到天线馈电点之间必须预留 **$\pi$ 型匹配电路**（由 1 颗串联元件和 2 颗并联元件组成，推荐封装 0402）。
- 靠近天线连接器/弹片处并联 1 颗 **超低结电容 ESD 保护二极管**（要求结电容 $< 0.5\ \text{pF}$，避免高频信号衰减与谐波失真）。

```
EC600M               L1 (串联)             Antenna Connector
RF_ANT ──────┬────────[ 0R ]────────┬──────>
             │                      │
           [ C1 ]                 [ C2 ]
             │ (并联)               │ (并联)
            GND                    GND
```

## 6. 低功耗休眠机制与电流优化

EC600M 模组支持标准休眠模式与增强型休眠模式（Enhanced Sleep Mode），配合网络侧 DRX/eDRX 可实现极低待机功耗。

### 6.1 休眠控制指令与模式配置

| 指令 | 参数与功能 | 典型应用与说明 |
| :--- | :--- | :--- |
| `AT+QSCLK=0` | 关闭休眠模式（默认状态） | 模块常驻工作，主串口与内部基带持续供电，功耗最高（15~30 mA） |
| `AT+QSCLK=1` | 启用串口硬件 DTR 引脚控制休眠 | **最常用工业模式**：主控拉高 DTR 允许休眠，拉低 DTR 强制唤醒 |
| `AT+QSCLK=2` | 自动休眠模式（通过主串口数据控制） | 模块空闲若干秒后自动进入休眠；串口收到数据后自动唤醒 |
| `AT+QSCLKEX` | 增强型休眠模式配置（深睡眠与时钟切断） | 配置更激进的内部外设电源切断策略，休眠电流可低至 **$< 1.5\ \text{mA}$** |

### 6.2 DTR 与 MAIN_RI 唤醒时序与硬件逻辑
在 `AT+QSCLK=1` 模式下：
1. **主控让模块休眠**：
   - 主控将 `DTR` 引脚拉高（高电平 $\ge 1.35\ \text{V}$，或悬空）。
   - 模组处理完后台事务后，自动进入低功耗休眠状态。此时射频仅按网络寻呼周期（Paging Cycle）间歇侦听。
2. **主控主动唤醒模块**：
   - 主控将 `DTR` 引脚拉低（低电平 $\le 0.45\ \text{V}$）。
   - 等待至少 **20 ms ~ 50 ms** 后，主控即可通过主串口正常发送 AT 指令。
3. **模块收到网络呼叫/数据唤醒主控 (MAIN_RI 引脚通知)**：
   - 模块检测到网络下行短信、TCP/UDP 数据或 VoLTE 呼叫时，通过 `MAIN_RI` 引脚输出电平信号通知主控。
   - **短信通知**：RI 产生持续 **120 ms** 的低电平脉冲，随后恢复高电平。
   - **数据/呼叫通知**：RI 持续拉低，直到主控读取完数据或挂断后恢复高电平。
   - 主控检测到 RI 中断后拉低 DTR，唤醒模块并读取串口数据。

### 6.3 休眠功耗调试与漏电流排查 Checklist
1. **检查 GPIO 状态**：休眠前检查所有连向 3.3V 主控的 I/O 引脚，确保没有高电平倒灌或浮空输入状态。
2. **关闭不需要的外设与 URC**：
   - 通过 `AT+QURCCFG` 限制不必要的频繁上报。
   - 切断 USB 接口供电（若 USB VBUS 持续供电，模块会认为处于 USB 连接状态而无法完全进入深休眠）。
3. **确认网络 DRX 参数**：向运营商基站协商合理的寻呼周期，寻呼间隔越大（如 1.28s / 2.56s），平均休眠电流越小。
