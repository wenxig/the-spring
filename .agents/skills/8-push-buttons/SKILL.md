# 8 Push Buttons V1.02

用于项目中的 8 键独立按键板。商品图显示板上有两排共 8 个轻触按键，丝印编号为 `S1` 到 `S8`，顶部为 9 针排针。

## 已确认的排针定义

排针从标注 `G` 的一端开始，依次为：

| 物理顺序 | 丝印/信号 | 说明 |
| ---: | --- | --- |
| 1 | `G` | 公共地，连接 ESP32-P4 GND |
| 2 | `K8` | 按键通道 8，对应 `S8` |
| 3 | `K7` | 按键通道 7，对应 `S7` |
| 4 | `K6` | 按键通道 6，对应 `S6` |
| 5 | `K5` | 按键通道 5，对应 `S5` |
| 6 | `K4` | 按键通道 4，对应 `S4` |
| 7 | `K3` | 按键通道 3，对应 `S3` |
| 8 | `K2` | 按键通道 2，对应 `S2` |
| 9 | `K1` | 按键通道 1，对应 `S1` |

按下某个按键时，其 `Kx` 信号与 `G` 导通。`K1` 到 `K8` 是 8 路独立输入，不是行列复用矩阵；代码和接线应按 8 路 GPIO 输入处理。

## ESP32-P4 接线约束

- `G` 接 ESP32-P4 的公共 `GND`。
- `K1` 到 `K8` 分别接 8 个可配置为输入的 GPIO，当前四板方案按 S1～S8 分配 GPIO4/20/23/26/27/46/47/48，具体 P6 位置见 [接线方案](../../../packages/hardware/README.md)。
- GPIO 输入使用内部上拉或外部上拉，按键按下读为低电平（active-low）。不要把 `K1` 到 `K8` 配置为推挽输出。
- 未使用的按键通道保持断开或按项目 GPIO 复用表处理，禁止把相邻 `Kx` 信号短接。
- 排针顺序和 `Kx` 逻辑编号不同：排针从 `K8` 递减到 `K1`，编写连接表和线束定义时要明确区分物理顺序与逻辑编号。

## 软件扫描

- 初始化 8 个 GPIO 为输入上拉。
- 定时读取 `K1` 到 `K8`，将低电平转换为按下状态。
- 对每一路做消抖，推荐稳定时间约 10--30 ms；长按、连发和事件派发由上层策略决定。
- 输入状态应使用固定顺序 `S1`、`S2`、...、`S8` 暴露给业务层，避免直接依赖排针从左到右的物理顺序。
- ESP32-P4 的具体 GPIO 号、驱动 API 和任务调度遵循项目现有固件架构，不在本 skill 中硬编码。
