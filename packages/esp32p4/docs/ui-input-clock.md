# 按键、主界面与休眠

## 按键映射

| 按键 | GPIO | 语义 |
| --- | ---: | --- |
| S1 | 4 | 上 |
| S2 | 20 | 下 |
| S3 | 23 | 左 |
| S4 | 26 | 右 |
| S5 | 27 | 确定 |
| S6 | 46 | 取消 |
| S7 | 47 | 休眠/唤醒 |
| S8 | 48 | 主界面 |

按键服务使用 active-low 上拉输入，GPIO ISR 只投递边沿，`InputTask` 做 20 ms 消抖、长按和重复事件。UI 任务消费语义化事件，不直接读取 GPIO。

## 数字时钟主界面

主界面显示 `HH:MM` 为主，秒和日期作为次级信息；S8 随时返回主界面。时间来自统一 `SystemClock`，由 SNTP、蜂窝网络时间或 RTC 校准，界面只读取快照，不自行累加时间。

## 休眠

S7 先把休眠页面提交到显示服务，再触发电子纸深睡和非必要任务暂停。系统保留 RTC/低功耗定时器运行，时间继续推进；唤醒时先退出电子纸深睡，再重新读取 `SystemClock`，强制电子纸全刷以建立可靠帧基线。若产品后续要求屏幕显示休眠期间仍可见时间，则采用定时局部刷新唤醒策略，并单独评估电子纸残影与功耗。

休眠唤醒源包括 S7、任意按键和配置的定时器。网络与 modem 是否保持注册由电源策略决定，但恢复后必须通过统一状态快照重同步。
